## Описание программы
Кратко: консольное приложение для управления коллекцией книг. Позволяет добавлять, редактировать, удалять, фильтровать книги, сохранять и загружать данные в JSON, вести историю действий.

---

## Требования для запуска

- Python 3.10 или выше
- Библиотеки: нет внешних зависимостей (используются стандартные модули)

---

## Как запустить
git clone https://github.com/alekproekt-creator/BookTracker
cd book-tracker
python main.py

## Как пользоваться

1. При запуске появляется меню:

- 1 — Показать все книги
- 2 — Добавить книгу
- 3 — Редактировать книгу
- 4 — Удалить книгу
- 5 — Фильтрация
- 6 — История
- 7 — Сохранить
- 8 — Загрузить
- 9 — Выход

2. Выбери пункт, вводи данные по запросам.
3. Поля не должны быть пустыми; страницы — положительное целое.
4. Данные сохраняются в books.json при выборе "Сохранить" (или при подтверждении при выходе).

Структура проекта

- main.py — основной скрипт (модель Book, функции загрузки/сохранения, меню и команды)
- books.json — файл данных (создаётся при сохранении)

Примеры команд

- Добавить книгу: выбрать 2, ввести название, автора, жанр, количество страниц.
- Редактировать книгу: выбрать 3, указать номер книги, ввести новые значения (оставить пустым, чтобы сохранить старое).
- Фильтрация: выбрать 5, указать критерий (title/author/genre), ввести поисковую строку.
- История: выбрать 6, просмотреть последние действия (add/edit/delete).
